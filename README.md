# Kwanzaa Jeopardy

A Jeopardy game about Kwanzaa and Christmas in Brazil, for playing in class.

**Play it:** https://eliascapital.github.io/kwanzaa-jeopardy/

Or download `index.html` and double-click it to open it in any web browser (no internet needed).

## How to play

- Click a box to show the clue, then click **Show answer**.
- Press ✓ or ✗ next to a team to add or take away the points.
- One hidden box is a **Daily Double** worth twice the points.
- When the board is done, click **Final Jeopardy**. Each team wagers some of its points first.
- Press **F11** for full screen. Don't refresh the page during a game: it resets the scores.
